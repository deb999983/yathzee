#### Key Features
- The game can be played by any no of players.
- The game can be initialzed with any no of dices.
- Rules can be customized as well.
- In each turn user gets two options
  - Either select a score and end his turn
  - Or select some dices to keep and the remaining dice count is rolled in the next turn.
- When the game ends scoreboard of each player is shown as well as the winner.
